1. pymath
Мой прогноз:
1. 2 + 3 * 4 = 14 (Сначала умножение 3*4=12, потом сложение 2+12=14)
2. (2 + 3) * 4 = 20 (Сначала скобки 2+3=5, потом умножение 5*4=20)
3. 17 // 5 = 3 (Целочисленное деление: 17 делится на 5 три раза)
4. 17 % 5 = 2 (Остаток от деления: 17 - (5*3) = 2)
5. -7 // 2 = -4 (В Python деление с остатком округляет в меньшую сторону, поэтому -3.5 превращается в -4)

Результат Python:
print(2 + 3 * 4)      # Вывод: 14
print((2 + 3) * 4)    # Вывод: 20
print(17 // 5)        # Вывод: 3
print(17 % 5)         # Вывод: 2
print(-7 // 2)        # Вывод: -4

1. Чем отличается / от //?
   / — это обычное деление. А // — это деление с округлением вниз, оно отбрасывает дробную часть и оставляет только целое число (например, 5 // 2 = 2).
2. В чем смысл остатка?
   Остаток показывает, сколько «лишнего» остается после деления нацело. Например, 7 % 3 = 1, потому что 3 помещается в 7 два раза, и остается еще 1.
3. Почему форматирование не устраняет неточность float?
   Компьютер хранит дроби неточно. Форматирование просто округляет число для красоты на экране, но сама ошибка внутри компьютера остается.
